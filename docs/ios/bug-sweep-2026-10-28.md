# General correctness sweep

Verified fixes in this batch:

- Item animation dimensions larger than, or not dividing, the PNG could divide by zero or index beyond decoded pixels. Invalid dimensions now reject the sprite and preserve missing-texture fallback geometry.
- Skin files were persisted before decoding; corrupt cached images prevented a fresh request on later launches. Cache reads now validate first, refetch corrupt entries, and store only valid decoded responses.
- Remote world replacement compared dimension type names, so distinct worlds sharing a type could retain chunks/entities. The comparison now includes the actual dimension key while retaining the prior type check.
- Item-frame shared invisibility metadata was ignored on receive and omitted from integrated-server snapshots. Both directions now carry it; partial metadata updates preserve the existing flag and a later flags packet can reset it.
- Remote lightning was omitted from object cleanup, allowing flashes to survive world changes. It is now cleared with the objects.
- Cancel/disconnect could join a worker blocked before the play writer existed. A close-only connection handle is registered before the handshake, cancellation closes it without acquiring the writer lock, and unfinished workers are not joined by the UI. Late connections are closed on registration after cancellation.
- Native pack searches ignored request order; old results/errors could replace newer state. Searches now have generation ownership.
- Duplicate pack installs, category changes during download, pre-deleted replacement ZIPs, and stale game-file completion callbacks could corrupt or misreport installed content. Downloads now retain ownership/kind and replace existing files atomically.
- Resource-pack toggles could lose concurrent changes, and deletion ignored disable errors/unconfirmed replies. Mutations now serialize and deletion requires confirmed disable.
- Authentication handover could report an old error after sign-out. Stale attempts are ignored.

Validation: 1,259 client-library tests passed (42 ignored), 150 game-binary tests passed (3 ignored), 19 control-tool tests passed. All seven focused network tests pass, including a local TCP peer deliberately stalling login and cancellation before socket registration. The 368-test Python suite passes (5 skipped). iOS client Clippy with warnings denied passes. Native launcher async regressions pass in Simulator; source remains uninstalled on physical devices for this sweep.

Known limits/findings for further work: synchronous DNS/connect/authentication itself can remain in a detached worker until its underlying call returns, although cancellation no longer waits on it and it cannot activate a late game connection. Generic remote item/block-display entity rendering remains a feature gap. A persisted Microsoft profile with unavailable/missing keychain credentials still needs a distinct reauthentication-status treatment; do not simply delete profile data on an undifferentiated keychain error.

The navigation correction is separate: native SwiftUI TabView with exactly Play/Packs/Settings, using the system's Liquid Glass on supported releases and native pre-26 appearance on iOS 18. Experimental manual dock metrics and material were removed in accordance with Apple's standard-navigation guidance.
